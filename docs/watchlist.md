# Watchlist

The Watchlist is separate from portfolio holdings. It stores research
candidates without treating them as owned positions.

## Features

- Add, edit and remove NSE stocks.
- Store a reference price, target price and alert price.
- Assign priority and research status.
- Record an investment thesis and research notes.
- View current price, target upside and change from reference price.
- Refresh price history for a selected stock.
- Review 1-, 3-, 6- and 12-month returns.
- Review one-year volatility and maximum drawdown.
- Compare price with 50- and 200-day moving averages.
- View a valuation snapshot and deterministic watchlist signals.

The feature does not use an LLM or require an AI API key. Metrics are
descriptive research inputs and are not buy/sell recommendations.
