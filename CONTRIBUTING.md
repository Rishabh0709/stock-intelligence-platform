# Contributing

Thank you for contributing to the Stock Intelligence Platform.

---

## Branch Strategy

Never commit directly to main.

Create a feature branch.

Example

feature/stock-explorer

feature/portfolio

feature/recommendation-engine

---

## Commit Convention

feat:

fix:

refactor:

docs:

test:

Example

feat: implement stock explorer

fix: resolve duplicate schema issue

refactor: centralize dependency injection

---

## Pull Request Checklist

- Code builds successfully

- Dashboard runs

- Database migrations applied

- Documentation updated

- Screenshots attached (UI changes)

---

## Coding Standards

- Use type hints

- Follow PEP8

- Keep functions small

- Add docstrings

- Avoid duplicate logic

- Business logic belongs in Services

- SQL belongs in Repositories

- UI belongs in Dashboard

---

## Philosophy

Write code that is easy to understand.

Optimize for maintainability before cleverness.
